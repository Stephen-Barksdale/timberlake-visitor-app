## The Problem

First-time guests need service times, directions, family-ministry information, and connection resources without searching several pages. This project brings those visitor tasks into one responsive experience while linking back to the church’s existing Wix website.

## Features

- First-visit hero with directions and service highlights
- Sunday and Wednesday schedules
- First-visit expectations
- Children’s, youth, and adult ministry links
- Church resource links
- Responsive mobile navigation using React state
- Semantic HTML, keyboard focus styles, and reduced-motion support
